# Kanban SaaS "BuildFlow" para constructoras pequeñas y startups

## Descripción: ¿Para qué sirve BuildFlow y cómo ayuda a la empresa?

BuildFlow es una aplicación Kanban diseñada para constructoras pequeñas que gestionan proyectos residenciales o comerciales. Sirve para organizar y visualizar el flujo de trabajo de obras, desde la planificación hasta la entrega, ayudando a equipos de 10-30 personas a coordinar tareas, evitar retrasos y optimizar recursos como materiales (marcos, vidrios, puertas).

## Cómo ayuda a la empresa

- Reduce retrasos: Tableros visuales muestran el estado de cada proyecto (ej.: "En Obra", "Control de Calidad"), asegurando que todos sepan qué hacer y cuándo.
- Mejora coordinación: Centraliza tareas de supervisores, obreros y administrativos, eliminando confusiones (ej.: quién instala vidrios).
- Ahorra dinero: Alertas de inventario evitan compras de última hora; integración con Mercado Pago agiliza cobros.
- Fácil de usar: Interfaz móvil intuitiva para gerentes en obra, sin necesidad de herramientas complejas como Procore.
- Aumenta confianza: Hitos gamificados (ej.: "Fase completada") motivan al equipo y muestran progreso claro a clientes.

## Listado simple de funcionalidades (MVP)

- Tableros Kanban: Columnas predefinidas ("Planificación", "En Obra", "Control de Calidad", "Entrega", "Pagos") con drag-and-drop para mover tareas (ej.: "Instalar marcos").
- Gestión de tareas: Crear/editar tareas con detalles (responsable, fecha, notas sobre materiales como vidrios).
- Integración con Google Calendar: Sincroniza plazos de obra con calendarios para citas y entregas.
- Integración con Mercado Pago: Facturación directa desde el tablero para pagos de clientes.
- Alertas de inventario: Notificaciones cuando materiales (ej.: puertas) están bajos.
- Acceso móvil: App responsive para supervisores en obra (usando tablet/celular).
- Colaboración básica: Invitar usuarios (gratis para 1 usuario, premium para equipos).

## Diferenciador

- Mapas interactivos con Google Maps API: Cada tablero incluye un mapa que muestra la ubicación de las obras, con pines para cada proyecto (ej.: "Obra en Calle X"). Los gerentes pueden ver tareas específicas por obra en el mapa, facilitando la logística.
- Gamificación: Progreso visual con barras de "hitos completados" (ej.: "50% de la obra lista") y alertas motivacionales para mantener al equipo enfocado.
- Integración local con Mercado Pago: Adaptado para Argentina, permite facturar y rastrear pagos directamente, a diferencia de herramientas genéricas como Trello.
